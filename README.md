# 🛠️ PrismDebug

**Debug Deneyimini Yeniden Keşfet!**

PrismDebug, Friday Night Funkin' için geliştirilen ve oyunun orijinal Debug panelini değiştiren gelişmiş bir debug arayüzüdür.

## ✨ Özellikler

- 🛠️ **Yenilenmiş Debug Paneli:** Orijinal FNF Debug arayüzünün yerine geçer.
- ⚡ **Hızlı Erişim:** `F6` tuşuyla Debug panelini açın.
- 🔍 **Detaylı Panel:** `CTRL + F6` kombinasyonuyla gelişmiş Debug paneline erişin.
- 🎮 **FNF Entegrasyonu:** Oyunun mevcut Debug sistemini temel alır.
- 🖥️ **Geliştirici Odaklı:** Debug işlemlerini daha erişilebilir hâle getirir.

## ⌨️ Kontroller

| Kısayol | İşlev |
|---|---|
| `F6` | Debug Panelini Aç |
| `CTRL + F6` | Detaylı Debug Panelini Aç |

## 🎮 Proje Hakkında

PrismDebug, Friday Night Funkin'in standart Debug panelini kendi arayüzüyle değiştirerek geliştirme deneyimini farklı bir seviyeye taşımayı amaçlar.

İster hızlı Debug panelini kullanın ister detaylı panele geçin, kontrol sizin elinizde!
